Lost Messages Routing - AI Improvements

Automatically classify lost/unattached email messages using AI-powered analysis through OpenWebUI.

Features

🤖 Automatic AI Classification

Uses OpenWebUI (or any OpenAI-compatible API) to automatically classify lost messages into categories:

  • Spam / Advertising
  • Bounce / DSN
  • Auto-Reply
  • Legitimate Reply
  • New Inquiry
  • Finance
  • Supplier / Vendor

📊 Confidence Scoring

Each classification includes a confidence percentage (0-100%):

  • Green: ≥80% confidence (high)
  • Orange: 50-79% confidence (medium)
  • Red: <50% confidence (low)

⚙️ Easy Configuration

Simple setup in Settings > General Settings > Lost Messages AI:

  • OpenWebUI server URL
  • API key (optional)
  • Model selection (glm-5:cloud, llama3, mistral, gpt-4, etc.)
  • Auto-classification toggle
  • Confidence threshold

🎯 Manual & Automatic Modes

Manual: Click "AI Classify" button on any message or batch classify from list view

Automatic: Enable auto-classification to process new messages automatically

Requirements

  • mail_manual_routing
  • mail_manual_routing_ux
  • OpenWebUI server or OpenAI-compatible API
  • Python requests library

Quick Start

  1. Install and configure OpenWebUI on your server
  2. Install this module
  3. Go to Settings > General Settings > Lost Messages AI
  4. Enter your OpenWebUI URL and select a model
  5. Enable auto-classification if desired
  6. Done! New unattached messages will be classified automatically
